# Christian Culture Global — source package

International Christian radio + Bible + music + articles portal for `/Global/`.

**Start:** `npm install && cp .env.example .env.local && npm run dev`.
**Build:** `npm run check`.
**Deployment:** serve `dist/` at `https://polskieradio.cc/Global/`.

Full Polish instructions: [docs/README_PL.md](docs/README_PL.md).

This is a functional source foundation and implementation kit, **not a verified production integration**. Complete the launch checklist before publishing.
